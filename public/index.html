MAL Scraper REST API

A simple RESTful API for scraping MyAnimeList data.

⚠️ Disclaimer: This API is for educational and personal use only. Please respect MyAnimeList's Terms of Service.

🏥 System

GET /health

Check server status and cache statistics.

🎌 Anime Endpoints

Top Anime

GET /api/anime/top

Get the top anime list.

  • ?type= all, airing, upcoming, tv, movie, ova, ona, special (default: all)
  • ?limit= 1-50 (default: 25)

Seasonal Anime

GET /api/anime/seasonal

Get currently airing seasonal anime.

Anime Detail

GET /api/anime/:id

Get full details for a specific anime ID.

📚 Manga Endpoints

Top Manga

GET /api/manga/top

Get the top manga list.

  • ?type= all, manga, novels, oneshots, doujin, manhwa, manhua (default: all)
  • ?limit= 1-50 (default: 25)

Manga Detail

GET /api/manga/:id

Get full details for a specific manga ID.

🔍 Search

GET /api/search?q={query}

Search for anime or manga.

  • ?q= Your search keyword (required)
  • ?type= anime, manga, all (default: anime)
  • ?limit= 1-50 (default: 20)

Built with Node.js, Express, Axios & Cheerio
